# AAD_25_26-Acceso-a-datos-Ismael-Garcia-Camacho

# Descripción del proyecto

Este proyecto es una aplicación de ejemplo que demuestra cómo acceder y manipular datos utilizando diversas tecnologías
y enfoques en el contexto de bases de datos. El objetivo principal es proporcionar una guía práctica para aprender a
interactuar con bases de datos relacionales y no relacionales, así como implementar operaciones CRUD (Crear, Leer,
Actualizar, Eliminar).
